# 20. FTUE(첫 사용자 경험)·온보딩 설계

> 목표: 첫 세션 12분 안에 "배치 → 자동전투 → 보상 → 영웅 획득"의 핵심 루프를 한 바퀴 돌리고, 로비에 다음 전투·스태미너 회복·일일 의뢰라는 복귀 이유를 남긴다. 튜토리얼은 별도 맵 없이 **실제 1막 전투 S001~S004 위에 오버레이**로 얹는다(13 §15 첫 세션 플로우의 상세).

## 1. 원칙
1. 설명보다 조작: 단계마다 요구하는 조작은 하나, 안내 문구는 2줄 이하.
2. 강제는 최소: 입력을 막는 **차단형** 단계는 S001 편성·시작, 첫 조합 3곳뿐. 나머지는 코치마크(건너뛰기 가능).
3. 실패하지 않는 첫 전투: S001·S002는 튜토리얼 보정(§5) 아래에서 기대 승률 ≥ 95%.
4. 보상은 즉시·가시적으로: 결과 화면 보상 행 카운트업 → 로비 상단 재화 바로 날아가는 연출.
5. 과금 노출은 첫 세션에 없음: 보석은 첫 클리어 보상으로만 등장. 보석 상점·월정액은 2회차 세션부터.
6. 상태는 서버 저장: 완료 단계는 `/ftue/steps`(21 문서)에 기록. 재설치·기기 변경 시 복원되고 완료 단계는 다시 보이지 않는다.

## 4. 참전 인원·레벨 규칙 (설계 결정)
- **문제**: 초기 슬롯 곡선(1 + Lv/4: Lv4 2명, Lv12 4명, Lv20 6명)으로는 1막 스토리의 참전 모드(S003 소대 2, S005 소대 4, S007 부대 4~8, S010 대군 6~10)를 용병 레벨이 따라가지 못했고, 전투 난이도 검증(B3)이 가정한 기대 팀(소대 4·부대 6·대군 8)과도 어긋났다.
- **결정 1 — 슬롯 곡선**: `economy.team_size_by_player_level`를 Lv1 1 → Lv2 2 → Lv3 3 → Lv4 4 → Lv6 5 → Lv8 6 → Lv10 7 → Lv12 8 → Lv16 9 → Lv20 10으로 바꿨다(01 문서 반영). 레벨업 EXP는 120 + 60×Lv(누적 Lv8 ≈ 2,520 ≈ 1막 전투 25회, Lv20 ≈ 13,680 ≈ 1막 완주).
- **결정 2 — 최소 인원 우선**: 참전 슬롯 = clamp(max(레벨 슬롯, participation.min), min, max). 스토리·퀘스트 전투의 최소 인원이 레벨 슬롯보다 우선한다. 서버 `/battle/start` 검증과 S06 슬롯 표시에 동일 적용(ProgressService).
- **결정 3 — 스토리 전투 개별 튜닝**: 스토리 76전투는 지역 전투의 구간 보정과 별개로 전투마다 난이도별 전력 배수를 맞춘다(`sim/tune_bosses.py --scope story`, 부록 B9). 단독 전투는 레온 고정이므로 레온으로 튜닝한다.
- 기대 레벨 가정(§5 검증과 동일): 스토리 1회당 지역·조우 전투 2회 → 누적 EXP ≈ 스토리 EXP × 3. S005 Lv4(4명), S009 Lv6(5명), S010 Lv7(5명 → 최소 6), S015 Lv11(7명).

## 6. 코치마크·툴팁 사양
- 구성: 딤(검정 70%) + 타깃 컷아웃(라운드 12) + 펄스 링(ember) + 말풍선(≤ 2줄, 240~360px) + [다음]/[건너뛰기]. 차단형은 [건너뛰기] 없음, 타깃 외 입력 무시.
- 위치: 타깃 기준 자동(상/하/좌/우), 세이프 에어리어 안. 전환 애니 종료 후 0.3s에 표시. 전투 중 콜아웃은 일시정지 없이 3s.
- 문자열 키(17 문서, `data/strings_ko.json`): `ui.ftue.{step_id}.title`, `ui.ftue.{step_id}.body` — 22단계 전부 ko/en 작성 완료. 서버 에러 문구는 `ui.error.{CODE}`(21 §3).
- 단계 ID: `deploy_drag`★ `deploy_start`★ `battle_hud` `result_reward` `speed_intro` `hero_acquired` `hero_detail` `lobby_coach_worldmap` `lobby_coach_heroes` `lobby_coach_shop` `deploy_second` `trait_intro` `guild_join` `craft_first`★ `equip_first` `encounter_intro` `affinity_intro` `stamina_intro` `daily_intro` `star_up_intro` `quest_intro` `hard_intro` (★ 차단형). `FtueState.completed`는 `deploy_drag`~`lobby_coach_shop` 10개 완료 시 true.

## 7. 복귀·리텐션 훅 (D1~D7)
- **D1(2회차 세션)**: 출석 1일차(보석 10 + 스태미너 물약 소), 일일 의뢰 3개 소개, 로비 "계속하기" 카드, 스태미너 완충 푸시.
- **D2~D3**: 조우 호감도 진행 표시(월드맵 초상 하단 게이지), 중복 영웅 첫 획득 시 승급 안내, 어려움 난이도 해금 안내.
- **D4~D7**: 영웅 서사 퀘스트 첫 해금, 1막 결전 목표 배너, 7일 출석 완주 보상(계층 3 영웅 선택권 1 — 무료 지급이므로 "영웅 직접 판매 없음" 원칙과 충돌하지 않음).
- 푸시(옵트인 각각): 스태미너 완충, 일일 리셋(05:00 KST), 현상금 주간 마감 24h 전. 하루 최대 2건.

## 9. 예외·접근성
- 네트워크 단절: 튜토리얼 전투 결과는 큐 저장, 보상은 서버 응답 후 반영(낙관적 UI 금지, 15 §3.6). 연결 대기 오버레이 2s 후 "다시 시도".
- 앱 종료 후 재진입: 마지막 완료 단계 다음부터. 전투 중 종료 → `/battle/sessions`로 세션 복구, 만료 시 무료 재도전.
- 접근성: 글자 크기 3단계(타이틀 ⚙에서도 변경), 색각 보정 팔레트(피아 식별은 색 + 외곽선 + 방향), 드래그 대신 탭-탭 배치(벤치 탭 → 칸 탭).
- 언어: 기기 언어로 ko/en 자동, 타이틀 ⚙에서 변경.
