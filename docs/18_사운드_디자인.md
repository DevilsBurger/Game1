# 18. 사운드 디자인 가이드 및 오디오 에셋 목록

> 톤: "잿빛 서사시"에 맞춘 오케스트라 + 민속 악기 + 국가별 색채(네오스는 신스, 녹스는 저음 합창). 전투는 TFT처럼 **정보 전달이 우선**(스킬 시전·처치·웨이브가 소리만으로 읽혀야 함).

## 1. 믹서 구조
```
Master
 ├─ Music (BGM)  ─ Lobby / Map / Battle / Cutscene (크로스페이드 1.5s, 전투 긴장도 레이어 3단)
 ├─ SFX
 │   ├─ UI (버튼·탭·토스트·보상)
 │   ├─ Combat (타격·스킬·사망·VFX) — 동시 발음 제한 12, 우선순위 보스 > 스킬 > 타격
 │   └─ Ambience (국가 환경음, 루프)
 └─ Voice (영입·로비·컷신 대사; 한국어 우선, 영어 2차)
```
- 전투 배속 2x/3x: SFX 피치 유지, 발음 빈도 제한(같은 소리 80ms 내 중복 금지).
- 스킵 시 보상 효과음만 재생.

## 4. 보이스
- 1차(한국어): 영입 대사 196 + 로비 대사 196 + 스토리 핵심 인물 12명의 컷신 대사(약 150줄) + 레온/카시안/엘리아/바르그라드 전투 외침(각 6종).
- 성우 캐스팅 가이드: 레온(낮고 건조, 30대), 카시안(젊고 냉소적), 엘리아(따뜻, 20대), 바르그라드(고대·저음·이중 레이어), 아젤리아(차갑고 위엄), 요한나(맑고 단호).
- 2차(영어): 동일 범위. 파일명 `vo_{lang}_{hero_id}_{key}.wav`.

## 5. 규격
- WAV 48kHz 24bit 원본 → Unity Vorbis(음악 q0.6, SFX ADPCM/PCM 짧은 것). 음악은 스트리밍, SFX는 메모리 로드. 모바일 -16 LUFS 통합 라우드니스, 피크 -1 dBTP.
- 네이밍: `bgm_nation_valheim.ogg`, `sfx_skill_dash_aoe_cast.wav`, `sfx_ui_reward_gold.wav`, `amb_nation_nox_loop.ogg`.
- 전투 SFX 우선순위·동시 발음 제한은 `AudioManager`(15 문서 Presentation) 설정값으로 노출.
