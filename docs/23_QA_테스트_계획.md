## 2. 자동화 파이프라인 (CI)
```
PR → python3 -m pytest tests -q (엔진·데이터·벡터·스키마·OpenAPI, 1분)
   → gen_schemas --validate, gen_csharp (생성물 diff 없음 확인)
   → Unity EditMode (Core 단위 + 벡터 41 비트 동일 + 성능 벤치 10v10 ≤ 20ms)
   → Unity PlayMode 스모크(Boot→Title→Lobby→S06→S07→S08, 목 서버)
nightly → Device Farm 스모크(저·중·고 3기기) + 스크린샷 diff + 메모리 스냅샷
weekly  → sim/run_all.sh 밸런스 회귀(B1~B7 지표 임계) + run_economy.py
```
- 게이트: L1~L4 실패 시 머지 금지. 벡터 불일치는 체크섬 첫 불일치 이벤트를 아티팩트로 첨부(15 §6.2).
- 생성물 규칙: `data/`, `unity/Generated/`, `docs/appendix/`는 생성기 출력이므로 손편집 금지. CI가 재생성 후 diff를 검사.

## 8. 릴리즈 체크리스트 (소프트 런치)
1. 빌드: 버전·빌드 번호, 서명, `min_client_version` 서버 설정, 데이터·밸런스 버전 태그, 어드레서블 카탈로그 CDN 업로드·캐시 무효화.
2. 서버: 점검 플래그 리허설, 마이그레이션 롤백 계획, 속도 제한·재시뮬 워커 용량(1,000 TPS), 알림(에러율·mismatch·결제 실패).
3. 스토어: 스크린샷·설명(ko/en), 연령 등급, 개인정보 처리방침 URL, 데이터 안전/개인정보 라벨, IAP 상품 가격·설명, 구독 약관 표기.
4. 법무: 확률형 아이템 아님(전투 드랍 확률 공개 UI 확인), 유료/무료 보석 구분 원장, 계정 삭제 경로, 미성년 결제 안내.
5. 운영: 공지·우편 템플릿, 고객 문의 FAQ(복구·결제·버그), 핫픽스 절차(21 §6), 대시보드 5종(22 §5) 가동.
6. 최종: L1~L4 CI 녹색, L8 매트릭스 전 기기 스모크, 신규 계정 FTUE 실기기 2회(저사양·고급), 기존 계정 업데이트 마이그레이션.

## 9. 라이브 QA
- 밸런스 패치: `sim/` 결과 → 스테이징에서 벡터·승률 확인 → 10% 롤아웃 → 24h 승률·mismatch 감시 → 100%. 임계 초과(난이도별 승률 ±8%p, mismatch > 0.1%) 시 ETag 롤백.
- 핫픽스: 데이터/밸런스는 서버 패치(앱 업데이트 없음), 코드 결함은 스토어 긴급 심사. 심각도 S1은 점검 공지 → 수정 → 보상 우편.
