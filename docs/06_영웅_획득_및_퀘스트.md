# 06. 영웅 획득 및 퀘스트

> 목표 4: 각 영웅을 얻는 전투를 포함하고, 보상에 영웅 획득을 추가. 1개의 전투로 확률 획득 + 여러 전투를 특정 조건으로 클리어하면 확정 획득.
> 원본: `data/battles.json`(kind=encounter/quest), `data/quests.json`. 전체 목록: [부록 A4](appendix/A4_퀘스트_목록.md).

## 1. 획득 경로 요약

| 경로 | 대상 | 방식 | 확정 여부 |
|---|---|---|---|
| ① 영웅 조우 전투 (196) | 전 영웅 | 전투 승리 시 계층별 확률 | 확률 + 호감도 천장 |
| ② 영웅 서사 체인 (70) | 계층 4·5 전원 | 조우 1회 클리어 후 3단계 조건 전투 | **확정** |
| ③ 출신 맹약 (14) | 출신별 계층 3 영웅 1명 | 출신의 계층 1~3 조우 전투 9개를 어려움 이상 클리어 | **확정** + 출신 상징 |
| ④ 직업 시련 (14) | 직업별 계층 2 영웅 1명 | 해당 직업만으로 3전투 | **확정** + 직업 상징 |
| ⑤ 스토리 (5막) | 브랜든·카시안·마리엘·에드릭(1막), 요한나(2막), 윌로우(3막), 아젤리아·이그니스(4막) | 스토리 전투 첫 클리어 | **확정** |
| ⑥ 지역 전투 일반 보상 | 토착 출신 계층 1~3 | 2/3/5% 무작위 | 확률 |
| ⑦ 호감도 천장 | 전 영웅 | 100 도달 후 조우 승리 | **확정** |

계층 1~3 영웅(126명)은 ①·③·④·⑥·⑦로, 계층 4·5(70명)는 ①·②·⑤·⑦로 얻는다. **모든 영웅에게 확정 경로가 존재**한다.

## 2. 영웅 조우 전투 (Encounter)
- 영웅마다 1개, 토착 국가의 지역에 배치(출신에 국가가 2개 이상이면 번갈아 배치. 예: 토르가 출신은 토르가·쿠르간·자이로스).
- 적 편성: 해당 영웅(보통 ★1 / 어려움 ★2 / 악몽 ★3) + 국가 세력 소대.
- 참전: 자유(1~10). 반복 가능. 스태미너 소모.
- 드랍 확률:

| 계층 | 보통 | 어려움 (×1.5) | 악몽 (×2.2) |
|---|---|---|---|
| 1 | 35% | 52.5% | 77% |
| 2 | 25% | 37.5% | 55% |
| 3 | 15% | 22.5% | 33% |
| 4 | 8% | 12% | 17.6% |
| 5 | 4% | 6% | 8.8% |

- 보정: 영웅 서약서(×1.5/×2/×3, 1회), 영웅의 부적 지원 아이템(+10%p), 리에스 특성은 골드만. 최종 상한 90%.
- 미획득 시 호감도 누적(계층별 +10/8/6/4/3). 100 도달 = 다음 승리에서 확정. 즉 **최악의 경우** 계층 5는 조우 34회, 계층 1은 10회면 확정.
- 첫 클리어 보너스: 호감도 +10, 파편, 보석 10.
- 보유 중인 영웅의 조우 전투는 "재회 전투"로 바뀌어 파편·호감도만 준다.

## 3. 영웅 서사 체인 (Hero Chain, 계층 4·5)
조우 전투를 1회 클리어하면 열린다. 3단계이며 각 단계는 **그 영웅이 레온에게 요구하는 증명**이다.

| 단계 | 이름 | 조건 예 |
|---|---|---|
| 1/3 첫 만남 | 계층 5: 해당 출신 영웅 2명 이상 포함 / 계층 4: 해당 직업 영웅 1명 이상 포함 | "아스텔 출신 2명 이상" |
| 2/3 신뢰의 증명 | 무작위 조건 1 | 어려움 이상, 전원 생존, 25초 이내, 4명 이하, 2성 이하, 계층 3 이하 |
| 3/3 맹약 | 무작위 조건 1 (2단계와 다름) | 위와 동일 풀 |

- 전투 유형은 시련·토벌·구출·호위·결투·방어·매복·탐험·암살·수호 중 무작위. 레벨은 국가 위험도 + 단계.
- 보상: **영웅 확정**, 골드 2,000×계층, 보석 30×계층, 출신 상징 1.
- 이미 보유한 상태로 클리어하면 파편 ×2 + 호감도 +30.

예) `HQ001 로이드 하트윈의 서사`: Q001-1(아스텔 출신 2명 이상) → Q001-2(아군 전원 생존) → Q001-3(계층 3 이하 영웅만) → 로이드 하트윈 확정 + 아스텔의 상징.

## 4. 출신 맹약 (Origin Pact, 14)
- 조건: 해당 출신의 계층 1~3 영웅 9명의 조우 전투를 **어려움 이상**으로 클리어.
- 보상: 출신의 계층 3 영웅 1명 확정(예: 아스텔의 맹약 → 가웨인 로스), 출신 상징, 골드 5,000, 보석 50.
- 의도: 조우 전투를 "복권"이 아니라 "컬렉션 진행"으로 느끼게 한다.

## 5. 직업 시련 (Class Trial, 14)
- 조건: 해당 직업 영웅만으로 3전투(2막 해금, 해당 직업 2명 이상 보유 시).
- 보상: 직업의 계층 2 영웅 확정 + 직업 상징 + 골드 3,000.
- 의도: 직업 시너지 체험 + 비조합 상징(포격수·주술사·음유시인·공학자)의 안정적 공급.

## 6. 스토리 보상
| 막 | 영웅 | 시점 |
|---|---|---|
| 1 | 브랜든 홀트(T2), 카시안(T3), 마리엘(T3), 에드릭 몬타뉴(T3) | 2·5·8·12번째 전투 |
| 2 | 요한나 루멘(T5) | 결전: 재의 함대 |
| 3 | 윌로우 하인즈(T5) | 폐기된 병기 |
| 4 | 아젤리아(T5), 이그니스(T5) | 아젤리아의 결단 / 결전 |

스토리 영웅은 조우·체인으로도 중복 획득 가능(파편 전환).

## 7. BM 연계: 서약서와 매력 징표
- **영웅 서약서**(문서): 조우 전투 입장 시 소비. 드랍 ×1.5(골드 600/보석 30), ×2(1,400/60), ×3(보석 150). "오늘 꼭 이 영웅을 얻고 싶다"의 가속.
- **매력 징표**: 지정 영웅 호감도 +10(골드 500/보석 25), +50(보석 110). "확정까지의 거리"를 직접 산다. 계층 5를 징표만으로 확정하려면 묶음 2개(220보석) = 서약서 전설 1.5장 가치로 설계.
- 둘 다 **골드 경로가 존재**(전설 서약서·징표 묶음 제외)하므로 무과금도 시간으로 해결.

## 8. 예상 획득 페이스 (무과금, 1일 240 스태미너/영웅 기준)
- 1막(1~5시간): 스토리 4명 + 조우로 계층 1~2 영웅 8~12명.
- 2막(10~20시간): 40~60명. 첫 계층 4·5는 체인으로.
- 전체 196 수집: 악몽 난이도 포함 약 150~200시간(호감도 천장 덕에 상한이 존재).

## 9. 퀘스트 데이터 구조
```
quest { id, kind(story|hero_chain|origin_pact|class_trial), name_ko, hero_id?, steps[{battle_id, condition{key, desc}}],
        unlock{act, requires_encounter_clear?, requires_owned_class_count?}, reward{hero_guaranteed?, gold, gems, items[]}, desc }
```
조건 키: `difficulty>=hard`, `no_death`, `time<=25`, `team_size<=4`, `max_star:2`, `max_tier:3`, `origin_count:{origin}:2`, `class_count:{class}:1`, `class_only:{class}`, `origin_only:{origin}`, `no_duplicate_class`.
