# 19. VFX 및 유닛 애니메이션 사양

> 엔진 타이밍과 **동기화**되는 것이 핵심: 공격 적중 프레임 = 엔진의 공격 판정 시점, 시전 0.3초 = 엔진 CAST_TIME, 피해 숫자는 `damage` 이벤트 시점. 전투 뷰는 `BattleEvent` 스트림(08 §9)을 소비한다.

## 1. 유닛 애니메이션 템플릿 (직업 14 × 6 상태)
| 상태 | 길이(24fps) | 규칙 |
|---|---|---|
| idle | 48f 루프 | 호흡·무기 미세 움직임. 출신별 소품 애니(네오스 홀로그램 깜빡임 등) |
| move | 24f 루프 | 엔진 이동 0.5초/칸 → 12f당 1칸 보간, 발소리 2회 |
| attack | 공속 1.0 기준 18f, **적중 프레임 10f** | 엔진은 공격 시 즉시 판정 → 뷰는 `attack` 이벤트 수신 시 애니 시작, `damage` 이벤트를 10f에 맞춰 표시(피해 숫자 지연 ≤ 0.4s). 공속 > 1.0이면 재생 속도 비례 가속(최대 2.5x) |
| cast | 12f(시전 0.3s) + 후딜 6f | `cast` 이벤트에 맞춰 시작, 12f에 스킬 VFX 발사 |
| hit | 8f | 피격 시 틴트(흰색 60ms) + 밀림 2px. 기절 중이면 star 아이콘 루프 |
| death | 20f + 페이드 10f | 종족별 변주: 인간 쓰러짐, 기계 폭발, 언데드 붕괴, 야수 쓰러짐, 용 재로 흩어짐 |
직업별 attack 모션: 기사(방패 밀치기+검), 전사(대검 휘두름), 암살자(이중 찌르기), 궁수(활 당김·발사 = 투사체), 마법사(지팡이 투사체), 사제(투사체 빛), 수호자(방패 타격), 결투가(2연 베기), 소환사(지팡이), 포격수(장전·발사, 적중 프레임 14f), 주술사(토템 흔들기), 음유시인(연주 파동), 용기사(창 찌르기), 공학자(렌치 투척).

## 2. 스킬 VFX 사양 (원형 34)
공통: 출신 악센트 색 틴트(12 §9), 지속 0.3~0.6s, 보드 좌표 기준 스프라이트/파티클, 알파 가산. 파티클 수 모바일 상한 60.

## 3. 아이템·특성 상태 표시
- 아이템 훅 발동(부활·무적·처형·폭발 등)은 짧은 아이콘 팝(0.5s) + 전용 SFX. 지속 버프는 유닛 바 아래 8px 아이콘 스트립(최대 4).
- 특성: 전투 시작 시 활성 특성 배너(좌우 패널에서 보드 쪽으로 0.3s 슬라이드), 임계값 효과(루멘 치명 회피·녹스 망령·네오스 폭발)는 전용 VFX.

## 4. 보스·구조물·웨이브
- 보스 등장: 1초 배너 + 보스 유닛 1.5~2배 스케일, 체력 바 상단 전용.
- 성벽: 피격 시 균열 단계 3(체력 66/33%), 파괴 시 붕괴 파티클. 수호 대상: 체력 50% 이하 시 경고 펄스.
- 웨이브 전환: 1.5초 정지, 배너, 다음 웨이브 유닛 우측에서 등장(0.4s 슬라이드).

## 5. 카메라·연출
- 보드 고정 카메라(줌 없음). 결전 보스 스킬·최종전만 0.2s 흔들림. 스킬 컷인(초상 0.4s)은 옵션.
- 피해 숫자: 위로 24px 상승·0.6s 페이드, 치명타는 1.3배·ember 색·살짝 회전. 동일 유닛 다수 피해는 0.1s 내 합산 표시.

## 6. 제작 파이프라인
- VFX: Unity VFX Graph(URP 2D 호환) 또는 파티클 시스템 + 스프라이트 시트(미드저니로 텍스처 참고 생성 가능: 불·서리·번개·성광·역병·홀로그램 6종 시트).
- 애니메이션: Spine 템플릿 14 직업 프로젝트 → 영웅별 스킨(파츠 교체). 보스 24는 개별 리그.
- 검수 체크리스트: 적중 프레임 동기(±2f), 배속 3x에서 가독성, 20유닛 동시 시전 시 60fps(중급 기기 30fps).
