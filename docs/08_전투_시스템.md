# 08. 전투 시스템

> 전투는 TFT(롤토체스)와 동일한 자동전투, 헥스 그리드. 각 케릭터의 전투 파라미터는 TFT와 동일.
> 기준 구현: `sim/engine/` (Python, 결정론적). 클라이언트(C#)는 이 규칙을 포팅한다.

## 1. 보드
- **헥스 그리드 8열 × 7행**(가로 화면). TFT는 7열 × 8행(세로 4열씩)이지만, 가로 모바일에 맞춰 **좌(아군 4열) ↔ 우(적 4열)**로 회전했다. 칸 수(28 vs 28)와 거리 관계는 TFT와 같다.
- 좌표: 오프셋 좌표(col 0~7, row 0~6), 큐브 좌표로 거리 계산. 홀수 행이 반 칸 밀린 "pointy-top" 헥스를 가로로 눕힌 형태.
- 아군 배치: col 0~3(최대 10유닛). 적: col 4~7. 매복은 아군 col 1~2 제한, 기습은 아군이 col 2~3에서 시작.
- 1칸 = 1 사거리. 근접 사거리 1, 궁수·마법사 4, 포격수 5.

## 2. 유닛 파라미터 (TFT 동일)
체력, 공격력, 공격 속도, 방어력, 마법 저항력, 사거리, 시작/최대 마나, 치명타 확률 25%, 치명타 피해 140%, 주문력 100, 피해 흡혈 0%, 내구력 0%, 이동 속도(1칸/0.5초).

## 3. 전투 루프
틱 = 1/30초. 전투 제한 30초, 이후 **연장 10초** 동안 모든 유닛이 받는 피해 +50%/초 누적(TFT 오버타임). 40초에도 승부가 없으면 생존 유닛 체력 비율 합이 높은 쪽 승리(무승부면 패배 처리, 스태미너 50%).

각 틱, 각 유닛은:
1. **상태**: 기절·속박 중이면 대기. 사망 시 제거(부활 효과 체크).
2. **타겟팅**: 타겟이 없거나 죽었으면 **가장 가까운 적**(동률 시 체력 낮은 쪽) 선택. 도발 중이면 도발자. 암살자 특성·도약 스킬은 "가장 먼/체력 최저 적"으로 재지정.
3. **이동**: 타겟이 사거리 밖이면 타겟 방향으로 인접 빈 칸 1칸 이동(A* 간이: 거리 감소 칸 중 첫 번째). 이동 중 공격 불가. 칸은 점유 배타.
4. **공격**: 사거리 내면 공격 타이머(1/AS초)에 따라 기본 공격. 원거리는 투사체(0.2초 비행, 명중 보장). 피해 = AD × (치명타 ? 치명타 피해 : 1). 공격 시 마나 +10.
5. **마나**: 최대 마나 도달 시 즉시 스킬 시전(시전 시간 0.3초, 시전 중 공격 불가, 마나 0으로). 피격 시 마나 +(받기 전 피해 1% + 받은 피해 7%), 1회 42.5 상한.
6. **지속 효과**: 화상·재생·오라·버프 시간 갱신.

## 4. 피해 공식
```
물리 피해 = 원피해 × 100/(100+방어력) × (1-내구력) × 피해 증감 배율
마법 피해 = 원피해 × 100/(100+마법저항) × (1-내구력) × 배율
고정 피해 = 원피해 × 배율
방어막 → 체력 순으로 차감. 흡혈 = 준 피해(방어 적용 후) × 흡혈%.
치명타: 기본 공격 25%/140%. 스킬은 '보석 장갑'류가 있을 때만 치명타.
```
- 방어력/마저 감소(삭감)는 비율로 적용, 음수 불가(최소 0).
- 화상: 최대 체력 %의 고정 피해/초, 치유 감소(33~50%)는 받는 치유·흡혈 모두 감소.
- 처형(execute): 잃은 체력 비례 추가 피해 또는 체력 % 이하 즉사.

## 5. 스킬 시전 규칙
- 스킬 원형 34종 ([03 영웅 시스템 §3](03_영웅_시스템.md)). 대상 선택: current(현재 타겟), farthest, lowest_enemy(체력 최저), cluster(인접 적 수 최다 칸), lowest_ally, adjacent_allies, all_allies, self.
- 도약(dash): 대상 인접 빈 칸으로 즉시 이동. 빈 칸 없으면 제자리에서 시전.
- 광역 반경(radius) 1 = 대상 포함 인접 6칸. 직선(line) = 시전자→대상 방향으로 대상 뒤 2칸.
- 소환수: 시전자 인접 빈 칸에 생성, 시전자 능력치 비율, 수명 12~15초, 동시 최대 수 제한. 포탑은 이동 불가·사거리 4.
- 버프 중첩: 같은 효과는 지속 시간 갱신(수치는 큰 값).
- 기절 중 마나 획득 없음, 수은 망토 등 CC 면역 시 기절·속박·둔화 무시.

## 6. 특성 활성
- 전투 시작 시 아군 편성(+상징)으로 출신/직업 카운트 산출 → 임계값별 효과 부여. 효과는 03 문서 §2 수치.
- "앞 2열"(기사 특성)은 아군 col 2~3(적과 가까운 두 열) 배치 유닛.
- 소환수는 특성 카운트에 포함되지 않는다.

## 7. 전투 유형별 특수 처리
| 유형 | 처리 |
|---|---|
| 웨이브(방어 3·생존 5·탐험 2~3·투기장 3) | 웨이브 종료 시 다음 적 생성, 아군 체력·마나·버프 유지, 타이머 리셋(웨이브당 30초) |
| 구조물 | 공격하지 않는 유닛. 성벽(적): 체력 ×6, 화살비 오라. 수호 대상(아군): 체력 ×3, 사망 시 패배 |
| 호위 | 호위 대상은 아군 측 비공격 유닛. 적 타겟팅이 호위 대상을 우선(가중 2배) |
| 결투 | 양측 1유닛, 연장 없음(40초 후 체력 비율) |
| 암살 | 지휘관 사망 시 즉시 승리 |
| 탈출 | 30초 경과 시 승리, 적은 무한 증원(5초마다 1) |
| 구출 | 간수 유닛 사망 전까지 아군 1유닛 '속박'(행동 불가, 피해 면역) |
| 매복 | 적을 좌우 양측 col 0~1, 6~7에 배치, 아군 col 3~4 |
| 레이드 | 보스 체력 ×4, 보스에게 CC 지속 50% |

## 8. 승리/패배 판정과 결과
- 승리: 적 전멸(또는 유형별 조건). 결과 화면에 전투 통계(피해량·받은 피해·치유·처치)와 퀘스트 조건 판정(전원 생존, 시간, 인원).
- 패배: 스태미너 50%, 보상 없음, 재도전 버튼(난이도 하향 제안).

## 9. 결정론과 재현
- 모든 난수는 전투 시드(서버 발급)로 생성. 같은 편성·시드 → 같은 결과. 리플레이는 시드 + 편성만 저장.
- 틱 순서: 유닛 ID 오름차순(아군 → 적). 동시 사망은 같은 틱 처리.
- Python 레퍼런스(`sim/engine/combat.py`)와 C# 포팅은 동일 테스트 벡터(`tests/`)를 통과해야 한다.

## 10. UI/연출 (요약, → 11 문서)
- 배속 1/2/3배, 자동 스킵(결과만). 유닛 위 체력/마나 바, 스킬 시전 시 초상 플래시. 가로 화면에서 보드는 중앙 70%, 좌측에 아군 특성 패널, 우측에 적 특성 패널.
