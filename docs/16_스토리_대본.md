자동 생성: `python tools/gen_story.py` (원본 `tools/script_data_1.py`, `script_data_2.py`, `script_lines.py`). 데이터: `data/story_script.json`.
화자 규칙: 레온(과묵, 계약·약속의 언어), 카시안(냉소 + 온기, 아버지에 대한 양가감정), 엘리아(온기), 재의 장군들(스카르 조롱 / 베스카 냉정 / 이르자 광신 / 모르가스 충성), 바르그라드(고대적·비통·위압), N = 내레이션.
