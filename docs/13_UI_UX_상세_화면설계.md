# 13. UI/UX 상세 화면 설계

> [11 UI/UX 화면 설계](11_UI_UX_화면_설계.md)의 상세판. 모든 좌표는 1920×1080 기준(Safe Area 좌우 44·상하 24). 토큰은 [12 디자인 시스템](12_그래픽_가이드라인_디자인시스템.md). 각 화면의 이미지 요구는 [14](14_이미지_에셋_목록_및_프롬프트.md)의 ID로 참조한다.

## 0. 공통 프레임

```
┌─────────────────────────────────────────────────────────────────────────┐ y=0
│ [44] ← 뒤로(88)  화면 제목(H1)          골드 ◆12,340  보석 ◇210  스태미너 ⚡120/150 [44] │ 상단 바 80
├─────────────────────────────────────────────────────────────────────────┤ y=80
│                                                                         │
│                      콘텐츠 영역 1832 × 920                              │
│                                                                         │
├─────────────────────────────────────────────────────────────────────────┤ y=1000
│   월드맵   │   영웅   │   상점   │   퀘스트   │   투기장   │   길드(설정)       │ 하단 탭 80 (로비 계열만)
└─────────────────────────────────────────────────────────────────────────┘ y=1080
```
- 상단 바: 재화 터치 → 보석 상점. 스태미너 터치 → 스태미너 상세(영웅별 목록). 뒤로 버튼은 좌상 고정(안드로이드 백키 동일).
- 하단 탭 아이콘 48 + 라벨 16. 신규 뱃지(ember 점). 전투·편성·결과 화면에서는 숨김.
- 로딩: 국가 키 아트 + 팁 텍스트 + 진행 바(ember). 1.5초 이하면 페이드만.
- 공통 제스처: 가로 스크롤(카드 목록), 롱프레스 400ms(툴팁/상세), 핀치 줌(월드맵), 드래그 앤 드롭(편성).

## 1. 타이틀 (S01)
- 배경 `BG-TITLE`(타이틀 키 아트: 재의 하늘 아래 레온과 청룡), 로고 `UI-LOGO` 중앙 상단(1200×400 영역), 하단 "화면을 터치하세요"(캡션, 깜빡임 1.5초).
- 좌하: 버전·계정(캡션). 우하: 공지·설정 아이콘(64).
- 최초 실행: 터치 → 프롤로그 컷신(`CS-00`) → 1막 1전투(튜토리얼). 재실행: 터치 → 로비.

## 2. 로비 — 브로멜 길드 홀 (S02)
```
┌ 상단 바 ──────────────────────────────────────────────────────────────┐
│ [일일 의뢰 3/3 ✓]  [출석]                               [우편 2] [공지] │ 좌상/우상 플로팅 버튼(64)
│                                                                      │
│   ┌ 패럴랙스 배경: 길드 홀 (BG-LOBBY, 3레이어) ─────────────────────┐ │
│   │       [스탠딩: 레온]   [영웅 A]   [영웅 B]   [영웅 C]            │ │ 터치 시 대사 말풍선(2초)
│   └───────────────────────────────────────────────────────────────┘ │
│ ┌ 스토리 다음 전투 ───────────────┐   ┌ 현상금 게시판 ───────────────┐ │
│ │ 1막 · 왕자의 결투 (결투·단독)     │   │ 이번 주 4/7 · 보상 ×2        │ │ 카드 640×160 / 480×160
│ │ [계속하기 ▶]                    │   │ [보기]                       │ │
│ └────────────────────────────────┘   └──────────────────────────────┘ │
├ 하단 탭 ──────────────────────────────────────────────────────────────┤
```
- 로비 스탠딩: 레온 고정 + 최근 영입/즐겨찾기 3명(영웅 상세에서 "로비 배치" 토글). `IMG-HERO-STAND-*`.
- 이벤트 배너는 좌측 상단 아래 세로 스택(최대 2개), 자동 롤링 없음(가로 화면 혼잡 방지).

## 3. 월드맵 (S03)
```
┌ 상단 바: 월드맵 ───────────────────────────────────────────────────────┐
│  가로 스크롤 대륙 지도 (BG-WORLDMAP 5760×1080, 3단계 줌)                │
│   ◉아스텔  ◉미르  ◉브로멜(홈)   ◎발하임(2막 잠금 🔒)  … 24개 국가 핀      │
│   핀: 국가 문장 아이콘 96 + 이름 + 위험도 ★×n + 진행률 링(지역 전투 %)      │
│                                               ┌ 국가 패널 (480 × 760) ─┐ │
│                                               │ 키 아트 썸네일 448×200   │ │ 핀 선택 시 우측에서 슬라이드
│                                               │ 아스텔 왕국 · 위험도 2   │ │
│                                               │ 설명 3줄 · 토착: 아스텔  │ │
│                                               │ 지역 5: 왕도 ●●●○○ …    │ │ 각 지역 행 = 진행 9칸
│                                               │ 조우 영웅 14 (보유 5)    │ │ 초상 64 가로 스크롤
│                                               │ 특산: 아스텔 왕실 검     │ │
│                                               │ [입장]                  │ │
│                                               └────────────────────────┘ │
├ 하단 탭 ─────────────────────────────────────────────────────────────────┤
```
- 막 미달 국가: 핀 흑백 + 🔒 + "N막 해금". 터치 시 조건 토스트.
- 지도 가장자리 안개(미해금 3·4·5막 영역은 구름으로 덮음, 막 클리어 시 걷히는 연출).
- 필터 칩(상단 좌): 전체 / 미클리어 / 조우 가능 / 현상금.

## 4. 국가 → 지역 (S04)
```
┌ 상단 바: 아스텔 왕국 ─────────────────────────────────────────────────────┐
│ 좌측 지역 리스트(360)                   │ 우측: 선택 지역의 전투 카드 그리드     │
│ ▸ 왕도 캐멀린   9/9 ★★★                │  [카드 320×180] × 9 (3열×3행)        │
│ ▸ 동부 국경 하론 7/9 ★★☆  ← 선택        │  카드: 유형 아이콘·이름·레벨·참전 모드   │
│ ▸ 서부 평원     0/9 🔒(이전 지역 5클리어) │        난이도 ★ 3개(클리어 표시)·보상 미리보기│
│ ▸ 남부 곡창지대                          │        영웅 조우 카드는 초상 + 드랍 % 강조 │
│ ▸ 북부 요새선                            │                                     │
│ [지역 배경 썸네일 360×200 BG-BOARD-*]    │  하단: 스토리 전투(이 국가) 가로 스크롤   │
└─────────────────────────────────────────┴─────────────────────────────────┘
```
- 카드 상태: 미해금(흑백, 🔒 + 조건), 신규(NEW 뱃지), 클리어(난이도별 ★ 금색), 반복 가능(↻).
- 카드 터치 → 전투 정보 모달(S05).

## 5. 전투 정보 모달 (S05)
```
┌ 모달 1400 × 820 ───────────────────────────────────────────────────────────┐
│ 동부 국경 하론 접전: 국경 도적              [유형: 소규모 접전]  [레벨 12] [×]  │
│ ┌ 적 편성 (좌 760) ───────────────┐ ┌ 난이도 탭: 보통 | 어려움 | 악몽 ────────┐ │
│ │ 초상 96 × n (계층 테두리, ★)     │ │ 적 전력 ×1.0 · 적 성급 ★1              │ │
│ │ 보스: 큰 초상 160 + 체력 ×2.0    │ │ 스태미너: 영웅당 10                    │ │
│ │ 적 특성: 도적단 2 · 궁수 2        │ │ 보상: ◆380  EXP 120  파편 4            │ │
│ │ 특수 규칙: 없음                  │ │ 아이템: 재료 30% · 조합 8%             │ │
│ │ 참전: 자유 (1~10)  ✓ 조건 만족    │ │ 영웅: 토착 무작위 2% (초상 9개 미니)    │ │
│ └─────────────────────────────────┘ │ 첫 클리어: ◆380 ◇7 파편 6              │ │
│ [서약서 사용 ▢] [부적 사용 ▢] (조우/드랍 관련 전투만)                          │ │
│                                    [편성으로 ▶]  (스태미너 부족 시 비활성+이유)│ │
└─────────────────────────────────────────────────────────────────────────────┘
```
- 악몽 탭은 적 배치 비공개(실루엣만). 조우 전투는 "기본 8% → 보정 12% · 호감도 40/100 (남은 조우 최대 N회)" 문구.
- 퀘스트 전투는 클리어 조건 체크리스트 표시.

## 6. 편성 (S06) — 핵심 화면
```
┌ 상단 바: 편성 · 동부 국경 하론 접전 (보통)                    [자동 편성] [프리셋 1 2 3] ┐
│ ┌ 아군 특성 패널 320 ┐ ┌──────────── 헥스 보드 1344×756 ────────────┐ ┌ 적 특성 320 ┐ │
│ │ 아스텔 2 (4) ●●○○    │ │  col0 col1 col2 col3 │ col4 col5 col6 col7  │ │ 도적단 2    │ │
│ │ 기사 2 (4)  ●●○○     │ │   ⬡   ⬡   ⬡   ⬡   │  ⬢   ⬢   ⬢   ⬢     │ │ 궁수 2      │ │
│ │ (활성: ember, 비활성 회)│ │   ⬡  [A]  [B]  [C] │  (적 실루엣/초상)    │ │ 특수 규칙    │ │
│ │ 터치 → 효과 툴팁       │ │   ⬡   ⬡  [D]  ⬡   │  ⬢   ⬢   ⬢   ⬢     │ │             │ │
│ │ 팀 인원 4/6           │ │                7행 (odd-q, 가로)           │ │ [적 상세]    │ │
│ └──────────────────────┘ └──────────────────────────────────────────────┘ └────────────┘ │
│ ┌ 벤치 (높이 180) ──────────────────────────────────────────────────────────────────┐ │
│ │ 필터: [출신▾][직업▾][계층▾][스태미너 충분만 ▢]  정렬: [계층][성급][이름]          │ │
│ │ [카드 120×150 가로 스크롤 … 보유 영웅 N명]  카드: 초상·★·계층 테두리·스태미너 바   │ │
│ └──────────────────────────────────────────────────────────────────────────────────┘ │
│                                      [출격 ▶] (ember, 높이 72, 우하 고정)              │
└──────────────────────────────────────────────────────────────────────────────────────┘
```
- 배치: 벤치 카드 드래그 → 아군 4열(또는 유형별 허용 열)의 빈 셀에 드롭. 보드 위 유닛 드래그로 재배치, 벤치로 드래그하면 해제. 셀 터치 시 허용 셀 점선 강조.
- 유닛 롱프레스 → 유닛 팝업(480×560): 능력치(성급 토글), 스킬, 아이템 3슬롯(드래그 또는 터치 선택), "재료 2개 → 조합 미리보기".
- 조건 검증: 인원 범위, 출신/직업 제한, 스태미너. 위반 시 출격 버튼 비활성 + 상단 바 아래 경고 줄(warning).
- 자동 편성: 전력 순 상위 N + 역할 균형(탱 2·딜 3·지원 1) 규칙, 전열(근접)·후열(원거리) 자동 배치.
- 프리셋 3개 저장(편성 + 아이템). 적 미리보기: 보통은 초상, 어려움은 실루엣+계층, 악몽은 수만 표시.

## 7. 전투 (S07)
```
┌ 좌: 아군 특성(활성만, 240) │  상단 중앙: 타이머 30.0 · 웨이브 2/5 · [1x 2x 3x] [스킵 ▶▶]  │ 우: 적 특성 240 ┐
│                            │  헥스 보드 (배경 BG-BOARD-*, 보드 오버레이 20% 투명)         │                 │
│                            │  유닛: 2.5등신 스프라이트 + 체력/마나 바(폭 88) + ★ + 기절 아이콘 │                 │
│                            │  피해 숫자: 물리 ivory, 마법 mana, 고정 gold, 치명 ×1.3 ember │                 │
│ 하단: 전투 로그 스트림(초상 48 + 스킬 아이콘, 최근 6개)   [일시정지 ⏸]                                       │
└─────────────────────────────────────────────────────────────────────────────────────────┘
```
- 스킬 시전: 초상 컷인(우측 하단, 0.4초, 옵션 off 가능) + 보드 위 VFX. 보스 등장 시 상단 배너 1초.
- 스킵: 첫 클리어는 비활성(연출 보장). 스킵 시 결과 즉시.
- 패배 예측(아군 전멸 확정 시) 0.5초 후 결과 화면.

## 8. 결과 (S08)
```
┌ 승리 배너(UI-BANNER-WIN, 금 오너먼트) / 패배(UI-BANNER-LOSE, 재)                                   ┐
│ 좌(1200): 보상 카드 플립 — 골드 · EXP · 아이템 · 재료 · [영웅 획득!] (초상 대형 + 호감도 바)            │
│           첫 클리어 보너스 행 · 퀘스트 조건 ✓/✗ (전원 생존 ✓ · 25초 이내 ✗)                           │
│ 우(600): 통계 탭 — 유닛별 피해/받은 피해/치유 막대(가로), MVP 초상                                     │
│ 하단: [다시] [난이도 변경 ▾] [다음 전투 ▶] [로비]                                                      │
└──────────────────────────────────────────────────────────────────────────────────────────────────────┘
```
- 영웅 획득 연출: 화면 딤 → 초상 등장(IMG-HERO-STAND) + 출신 색 광선 + 이름/칭호 디스플레이 서체 → "동료가 되었다".
- 미획득 시 호감도 증가 애니메이션("+6 · 46/100").

## 10. 상점 (S12) — 탭 6
```
┌ 탭: 대장간 | 무기고 | 유물관 | 보급소 | 보석 상점 | 판매 ──────────────────────────────┐
│ 대장간: 좌 재료 12 그리드(아이콘 96 + 가격 300) · 우 10×10 조합표(TFT 레시피 격자, 보유로 만들 수 있는 칸 ember 강조) │
│ 무기고: 분류 칩(조합/빛나는/상징/특수) · 그리드 6열 · 카드(아이콘 128·이름·효과 2줄·가격) · 터치 → 상세/구매 수량   │
│ 유물관: 유물/지원/국가 특산(국가 필터) · 특산품은 국가 문장 테두리                                               │
│ 보급소: 소모품(스태미너·서약서·징표·부적)·승급 재료(일일 한도 바 "파편 120/200")                                   │

```
