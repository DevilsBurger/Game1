# 11. UI/UX 화면 설계 (가로 모바일)

## 1. 화면 흐름
```
타이틀 → (최초) 프롤로그 컷신 → 1막 1전투(튜토리얼, 단독)
       → 로비(브로멜 길드 홀) ─┬─ 월드맵 → 국가 → 지역 → 전투 목록 → 전투 정보 → 편성 → 전투 → 결과
                               ├─ 영웅(목록/상세/승급/호감도/도감)
                               ├─ 상점(대장간/무기고/유물관/보급소/보석)
                               ├─ 퀘스트(스토리/서사 체인/맹약/시련/일일)
                               ├─ 투기장 · 현상금 게시판
                               └─ 설정/계정
```

## 2. 공통 레이아웃 (1920×1080 기준)
```
┌──────────────────────────────────────────────────────────────┐
│ [←] 화면 제목            골드 12,340  보석 210  스태미너(레온) 120/150 │ ← 상단 바 80px
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                       콘텐츠 영역 (920px)                      │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ 월드맵 | 영웅 | 상점 | 퀘스트 | 투기장 | 길드                    │ ← 하단 탭 80px (로비 계열)
└──────────────────────────────────────────────────────────────┘
```

## 3. 주요 화면

### 3.1 로비 (브로멜 길드 홀)
- 배경: 길드 홀 일러스트(가로 파노라마). 레온 + 최근 영입 영웅 3명이 서 있음(터치 시 대사).
- 좌: 일일 의뢰 요약, 우: 현상금 게시판 미리보기 / 스토리 다음 전투 바로가기(큰 버튼).

### 3.2 월드맵
- 가로 스크롤 대륙 지도(3단계 줌). 국가 핀에 위험도 별(1~10), 잠금 아이콘(막 미달), 신규 전투 뱃지.
- 국가 터치 → 우측 패널: 설명, 토착 출신, 지역 5개(진행률 n/9), 국가 특산품, 영웅 조우 목록(보유/미보유 초상).

### 3.3 전투 목록 / 전투 정보
- 지역 화면: 전투 9개 카드 가로 스크롤. 카드: 이름, 유형 아이콘, 레벨, 참전 모드, 클리어 난이도 별 3개.
- 전투 정보(모달): 적 편성(초상·계층·성급), 특수 규칙, 참전 조건(만족 여부 색상), **난이도 3탭**(적 전력·스태미너·보상·영웅 드랍률 "기본 8% → 보정 12%"), 첫 클리어 보너스. 서약서/부적 사용 토글.

### 3.4 편성 (핵심 화면)
```
┌ 아군 특성 패널 ┐ ┌──────────── 헥스 보드 8×7 ────────────┐ ┌ 적 특성 패널 ┐
│ 아스텔 2/4     │ │  ○ ○ ○ ○ │ ● ● ● ●                     │ │ 재의 날개 ...│
│ 기사 2        │ │   ○ ○ ○ ○ │ ● ● ● ●  (적 미리보기)       │ │             │
│ ...           │ │  ...     │ ...                          │ │             │
└──────────────┘ └──────────────────────────────────────────┘ └────────────┘
┌ 벤치: 보유 영웅 가로 스크롤 (필터: 출신/직업/계층/스태미너 충분) ┐  [자동 편성] [저장 프리셋 1 2 3] [출격]
```
- 드래그 앤 드롭 배치, 롱프레스로 영웅 상세·아이템 장착 팝업(3슬롯, 재료 2개 → 조합 미리보기).
- 참전 조건 위반 시 출격 버튼 비활성 + 이유 표시. 스태미너 부족 영웅은 회색.
- 적 미리보기는 실루엣 + 계층·성급(정보 공개 수준은 난이도별: 악몽은 배치 비공개).

### 3.5 전투
- 보드 중앙 70%, 좌우 특성 패널(활성 효과 강조), 상단 타이머·배속(1/2/3x)·스킵, 하단 전투 로그(스킬 시전 아이콘 스트림).
- 유닛: 체력 바(방어막은 흰색), 마나 바(파랑), 성급 별, 기절 아이콘. 스킬 시전 시 초상 컷인(0.4초, 옵션).
- 웨이브 전투: "WAVE 2/5" 배너, 웨이브 사이 1.5초 정지.

### 3.6 결과
- 승리/패배 배너, 보상 카드 플립(골드·아이템·재료·**영웅 획득 연출**: 확률 드랍 시 초상 등장 + 호감도 바), 퀘스트 조건 체크(전원 생존 ✓, 25초 이내 ✗), 통계 탭(유닛별 피해/받은 피해/치유).
- 버튼: 다시(같은 난이도) / 난이도 변경 / 다음 전투 / 로비.

### 3.7 영웅
- 목록: 그리드(가로 8열), 필터·정렬(출신/직업/계층/성급/스태미너/호감도), 미보유는 실루엣 + "획득 경로" 버튼(조우 전투로 이동).
- 상세: 좌 일러스트, 우 능력치(성급별 토글), 스킬, 특성, 장착 아이템 3슬롯, 서사, 호감도 바. 하단: 승급 버튼(재료 현황), 조우 전투 바로가기.
- 승급 화면: 재료 3종 + 골드, 승급 전후 능력치 비교, 연출.

### 3.8 상점
- 탭 6개(07 문서 §6). 대장간은 재료 10×10 조합표 UI(TFT 레시피 그리드) 제공. 보유 재료로 만들 수 있는 조합 강조.

### 3.9 퀘스트
- 스토리: 막별 진행 바(76전투), 다음 전투 버튼. 서사 체인: 영웅 초상 + 3단계 조건 체크리스트. 맹약/시련: 진행률 링.

## 4. UX 원칙
1. **가로 화면의 좌우 대칭**: 아군 정보는 왼쪽, 적 정보는 오른쪽. 보드 방향과 일치.
2. 한 손 조작 불가를 전제로, 양손 엄지 도달 영역(좌하·우하)에 주요 버튼(출격·배속·스킵).
3. 모든 확률 표기: 기본값 → 보정값, 호감도 천장까지 남은 횟수.
4. 전투 스킵 허용(TFT와 달리 PvE이므로 반복 플레이 피로 완화). 단, 첫 클리어는 스킵 불가(연출).
5. 접근성: 색각 보정 팔레트(아군 파랑/적 주황), 폰트 크기 2단계, 햅틱 옵션.

## 5. 아트 디렉션 (요약)
- 2D 세미 리얼 일러스트(초상) + 2D 스켈레탈 스프라이트(전투). 국가별 색채 팔레트(아스텔 은·청, 발하임 백·회, 사이람 적·흑, 카르나 금·사, 리에스 청록, 엘로웬 녹, 그란두르 동·철, 네오스 네온 시안, 녹스 보라·흑, 셀레스티아 백·금, 용족 색별 비늘, 토르가 갈·적, 루멘 백·금, 브로멜 회색 늑대).
- 보드 스킨은 지역마다(설원·사막·갑판·돔 내부·부유섬·재의 황야).
