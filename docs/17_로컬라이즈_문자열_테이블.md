# 17. 로컬라이즈 문자열 테이블

자동 생성: `python tools/gen_strings.py`. 산출물: `data/strings_ko.json`, `data/strings_en.json`(평탄 키→문자열), `data/strings_unity.csv`(Unity Localization CSV Extension 임포트용: Key, Korean(ko), English(en)).
원본: 한글은 데이터(JSON)·대본에서 추출, 영문은 `tools/strings_en_1.py`(UI·특성·국가·세력·몬스터·전투 유형·템플릿), `strings_en_2.py`(영웅 칭호·스킬·서사, 아이템 효과 템플릿), `strings_en_3.py`(컷신).

## 키 체계

```
ui.{section}.{key}                    UI 문자열 ({act}, {n} 등 중괄호 치환자 사용)
origin.{key}.name|desc|synergy       출신 특성
class.{key}.name|desc|synergy        직업 특성
hero.{id}.name|title|lore|skill_name|skill_desc   영웅 (P000 레온, NPC_ELIA 엘리아 포함)
item.{id}.name|desc                 아이템 (영문 desc는 능력치+훅 템플릿으로 생성)
nation.{key}.name|desc|capital|ruler|category   국가
region.{nation}.{0..4}               지역
faction.{ko}                         적 세력
monster.{key}.name                   몬스터
battle_type.{key}.name|desc|rule     전투 유형
battle.{id}.name|flavor              전투 1,604 (영문은 템플릿 치환)
quest.{id}.name|desc                 퀘스트 103
story.{battle_id}.pre|post.{i}, story.{battle_id}.direction   스토리 전투 대사
cutscene.{id}.title|shot.{i}.visual|shot.{i}.line.{j}      컷신
recruit.{hero_id}, lobby.{hero_id}.{i}   영입·로비 대사
speaker.{ko}                         화자 표시명
```

## Unity 임포트

1. Package Manager: Localization + CSV Extension. 2. Locales ko-KR, en-US 생성. 3. String Table `Game` 생성 후 `data/strings_unity.csv` 임포트(Key 열 = 키, 열 헤더의 로케일 코드 매칭).
4. 코드: `LocalizationSettings.StringDatabase.GetLocalizedString("Game", "hero.H001.name")`. 치환자는 Smart String `{act}` 형식으로 그대로 사용. 5. 데이터 재생성 시 CSV를 다시 임포트(키 안정: 데이터 ID 기반).

## 번역 규칙

- 영문 길이 확장 +30%를 UI 폭에 반영(12 문서 §3).
