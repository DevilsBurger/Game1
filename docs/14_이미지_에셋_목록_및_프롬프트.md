## 2. 프롬프트 체계

```
[카테고리 프리픽스] + [대상 서술: 성별·연령·외형·핵심 소품] + [칭호] + [직업 실루엣] + [출신 룩] + [계층 장식 수준]
+ [국가 팔레트: primary/secondary/accent HEX + 재질 + 광원] + [배경 지시] + [무드 앵커] --ar --stylize --sref --cref --no
```
| 요소 | 내용 |
|---|---|
| 무드 앵커(공통) | `painterly digital illustration, stylized dark fantasy, ash-grey atmosphere with ember-orange accents, dramatic rim light, muted palette with one saturated accent, cinematic composition, high-end mobile RPG splash art quality, clean readable silhouette, no text` |
| 출신 룩 14 | 예: 네오스 `hidden hi-tech civilization aesthetic, sleek titanium armor plates, cyan holographic HUD elements, clean sci-fi lines mixed into a dark fantasy world` / 용족 `humanoid dragonkin, subtle scales on cheeks and forearms, small horns, slit pupils…` (전체: `tools/gen_prompts.py` ORIGIN_LOOK) |
| 직업 실루엣 14 | 예: 포격수 `long-range artillerist with a siege weapon or cannon` (CLASS_LOOK) |
| 계층 장식 5 | T1 `simple practical gear` … T5 `legendary regalia, elaborate silhouette, powerful aura effects` |
| 국가 팔레트 24 | `design/palette_nations.json`의 HEX·재질·광원을 문장으로 삽입 |
| 카테고리 파라미터 | 초상 `--ar 1:1 --stylize 200`, 전신 `--ar 2:3 --stylize 200 --cref`, 유닛 시트 `--ar 3:2 --stylize 120 --cref --cw 60`, 아이템 `--ar 1:1 --stylize 150`, 배경 `--ar 16:9 --stylize 200~250`, 컷신 `--stylize 300`, UI `--stylize 100~180` |
| 네거티브 | `--no text, watermark, logo, signature, frame, border, blurry, extra limbs, deformed hands` |
| 버전 | Midjourney v7 기준(`--sref`, `--cref`, `--cw` 사용). 버전에 따라 파라미터명 조정 |

### 2.1 영웅 서술 규칙 (HERO_DESC, 196명 수작업)
- 성별·연령·체형·표정·핵심 소품을 한 줄로. 서사(lore)에서 시각화 가능한 요소만 추출(예: 하워드 크레인 "손이 떨려도 조준은 틀리지 않는다" → `trembling but precise hands, shoulder-mounted crossbow ballista`).
- 스토리 핵심 인물은 관계 단서를 포함(카시안 `son of the black dragon`, 바르토스 `Leon's mentor`).
- 네오스는 코드명 유닛(ORB-9, AEGIS-1 등)을 안드로이드/드론으로, 인간 과학자(윌로우·이오·카이 등)는 사이보그·연구자로 구분.

### 2.2 유닛 시트 → 리깅 파이프라인
1. 프롬프트의 `design sheet, front three-quarter view and side view, flat even lighting, solid light-grey background`로 생성(--cref 초상).
2. 정면 3/4 뷰 선택 → 배경 제거 → 파츠 분리(머리·몸통·팔 2·다리 2·무기·망토) → Spine 2D 리깅 → 공용 애니메이션 템플릿(직업별 14종 템플릿: idle/move/attack/cast/hit/death)에 바인딩.
3. 크기 규격: 유닛 높이 512px(보드 셀 96px 기준 5.3배 원본), 보스 768px. 아군/적은 테두리 색으로 구분(엔진 셰이더).

### 2.3 일관성 관리
- `--sref` 4종(초상/유닛/아이템/배경) + UI 1종을 앵커 세트에서 확정하고 **모든 프롬프트의 `<SREF_*>`를 치환**(`tools/gen_prompts.py`의 SREF 딕셔너리).
- 같은 영웅은 초상 URL을 `<PORTRAIT_URL>`에 넣어 전신·유닛 시트에 `--cref` 적용.
- 국가별 보드 배경 5장은 같은 세션에서 연속 생성(`--seed` 고정 권장).

## 4. 수량 산정 근거
- 영웅: 196 + 플레이어 레온 + 엔딩 NPC 엘리아 = 198. 성급별 일러스트는 공통(테두리·이펙트로 구분).
- 몬스터: `data/battles.json` monsters 118종. 보스급(계층 4~5) 24종만 초상·전신 추가.
- 아이템: 282 전부(소모품·재료 포함). 상징 28은 출신/직업 문장을 메달리온으로 통일.
- 배경: 국가 24 + 지역 120 = 144. 컷신 25(프롤로그 1 + 막별 4~6). UI 9 + 벡터 아이콘 117.
- 리깅 애니메이션: 197 영웅 유닛 + 118 몬스터 + 14 소환/구조물 = 329 리그, 직업 템플릿 14종 재사용.
