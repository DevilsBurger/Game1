## 저장소 구조
```
docs/          설계 문서 (본 색인)
design/        디자인 토큰(tokens.json), 국가 팔레트(palette_nations.json), 스타일가이드 미리보기(styleguide.html)
data/          게임 데이터 JSON (heroes, traits, items, nations, battles, quests, economy, prompts)
tools/         데이터 생성기 (roster_data, world_data, story_data, gen_*, export_md)
sim/           자동전투 시뮬레이터 + 밸런스 러너 + 보고서
tests/         엔진/데이터 테스트
```

## 재생성
```bash
python3 tools/gen_heroes.py && python3 tools/gen_items.py && python3 tools/gen_world.py
sh sim/run_all.sh                                       # 밸런스 전체 파이프라인 (4코어 약 25분)
sh sim/run_followup.sh                                  # 후속: 특성·아이템 조합·상황 아이템·보스·테스트 벡터 (약 20분)
python3 sim/fill_doc.py                                 # 09 문서 결과 요약 갱신
python3 tools/gen_prompts.py                            # 미드저니 프롬프트 부록 C1~C4 재생성
python3 -m pytest tests -q
```
