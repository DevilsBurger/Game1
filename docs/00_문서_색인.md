## 저장소 구조
```
docs/          설계 문서 (본 색인)
design/        디자인 토큰(tokens.json), 국가 팔레트(palette_nations.json), 스타일가이드 미리보기(styleguide.html)
schemas/       데이터 JSON 스키마 7종 + enums.json (tools/gen_schemas.py)
unity/         Unity용 생성 코드: Generated/*.cs(DTO·enum·토큰 — gen_csharp.py, 서버 API DTO NetDtos.cs — gen_netdtos.py), UI/theme.uss
server/        메타 서버 API 계약 openapi.yaml (21 문서)
data/          게임 데이터 JSON (heroes, traits, items, nations, battles, quests, economy, prompts, story_script, strings_ko/en, strings_unity.csv, art_tracker.csv, analytics_events)
tools/         데이터 생성기 (roster_data, world_data, story_data, gen_*, export_md)
sim/           자동전투 시뮬레이터 + 밸런스 러너 + 경제 시뮬 + 보고서
tests/         엔진/데이터/벡터/스키마/OpenAPI/전투 유형 규칙 테스트
```

## 재생성
```bash
python3 tools/gen_heroes.py && python3 tools/gen_items.py && python3 tools/gen_world.py
sh sim/run_all.sh                                       # 밸런스 전체 파이프라인 (4코어 약 25분)
sh sim/run_followup.sh                                  # 후속: 특성·아이템 조합·상황 아이템·보스·테스트 벡터 (약 20분)
python3 sim/fill_doc.py                                 # 09 문서 결과 요약 갱신
python3 tools/gen_prompts.py                            # 미드저니 프롬프트 부록 C1~C4 재생성
python3 tools/gen_schemas.py --validate && python3 tools/gen_csharp.py   # 스키마 검증·C#/USS 생성
python3 tools/gen_netdtos.py                             # server/openapi.yaml → unity/Generated/NetDtos.cs
python3 sim/make_vectors.py                              # C# 포팅 검증 벡터 재생성
python3 tools/gen_story.py && python3 tools/gen_strings.py   # 스토리 대본(16)·문자열 테이블(17)
python3 tools/gen_art_tracker.py && python3 tools/gen_analytics.py   # 아트 트래커 CSV·애널리틱스 사전(22)
python3 sim/run_economy.py                               # 경제 진행 시뮬레이션 (07 §9)
python3 sim/validate_tutorial.py                         # 1막 튜토리얼 전투 승률(레온 포함) → docs/20 §5
python3 sim/judgment_table.py                            # 잔여 밸런스 판단표 B8
python3 sim/tune_bosses.py --scope story --steps 7 --fights 24   # 스토리 76전투 개별 튜닝 → B9 (약 10분)
python3 -m pytest tests -q
```
