## 1. 게임 개요

### 1.1 한 줄 요약
"왕좌의 게임"처럼 여러 국가가 얽힌 대륙 **아르켄**에서, 떠돌이 용병 **레온 바르크**가 납치된 연인 **엘리아**를 되찾기 위해 **196명의 영웅**을 모아 TFT 방식의 자동전투로 **1,600여 개의 전투**를 치르며, 세계를 '재'로 되돌리려는 용족 집단 **재의 날개**를 막는 수집형 오토배틀러 RPG.

### 1.2 핵심 특징
1. **TFT 동일 전투 규칙**: 헥스 그리드, 자동 전투, 마나·스킬, 성급(1~3성), 출신/직업 시너지, 재료 2개 조합 아이템. TFT 경험자가 설명 없이 바로 이해한다.
2. **PvE 캠페인 중심**: 상점/캐러셀 대신 **전투 보상**으로 영웅·아이템·재료를 얻는다. 24개 국가, 1,604개의 전투(스토리 76 · 지역 1,080 · 영웅 조우 196 · 퀘스트 252), 각 전투 3단계 난이도.
3. **용병 콘셉트**: 혼자(단독) 참전부터 대군(10명) 참전까지, 전투마다 **참전 조건**이 다르다. 전투에 나가는 것이 곧 돈벌이다.
4. **판타지 × SF 혼합 세계**: 기사 왕국·북방 전사·동방 제국·사막 술탄국·해양 연합·엘프·드워프 같은 판타지 국가와, 고립된 **고도 과학 문명 네오스**, **흑마법 국가 녹스**, **고마법 부유섬 셀레스티아**가 공존한다.
5. **영웅 획득의 두 축**: 영웅 조우 전투(확률 드랍 + 호감도 천장)와 조건부 다단계 퀘스트(확정 영입).
6. **공정한 BM**: 과금은 스태미너(참전 횟수)와 영웅 드랍 확률/호감도(서약서·매력 징표)에만 관여한다. 능력치 직접 판매 없음. 모든 아이템은 골드로 구매 가능.

## 2. 핵심 플레이 루프

```
[로비(브로멜 길드)] ─→ [월드맵: 국가/지역 선택] ─→ [전투 선택 + 난이도 선택]
       ↑                                                   │
       │                                            [참전 조건 확인]
       │                                                   ▼
[보상: 골드·아이템·재료·영웅] ←─ [자동 전투 (TFT)] ←─ [편성: 헥스 보드 배치 + 아이템 장착]
       │
       ▼
[성장: 승급(성급)·아이템 조합·상점 구매·퀘스트 진행] ─→ 다시 월드맵
```

**세션 설계**: 1회 전투 30초~90초(웨이브 전투 최대 3분). 편성 포함 3~5분. 하루 3~5세션, 세션당 10~15분을 목표로 스태미너를 설계한다 (→ [07 경제/BM](07_경제_및_비즈니스모델.md)).

### 2.1 미시 루프 (전투 1회)
1. 전투 정보 확인: 적 편성(출신/직업·계층·성급), 유형별 특수 규칙, 참전 조건, 3난이도 보상.
2. 편성: 참전 가능한 영웅 중 스태미너가 충분한 영웅을 헥스 보드 좌측 4열에 배치. 아이템 장착(영웅당 3슬롯).
3. 자동 전투: TFT 규칙으로 진행. 배속(1x/2x/3x), 스킵(결과만 보기) 지원.
4. 결과: 승리 시 보상 지급, 첫 클리어 보너스, 퀘스트 조건 판정(전원 생존·시간 등). 패배 시 스태미너의 50%만 소모.

### 2.2 중기 루프 (지역/국가)
- 국가는 **막(Act)** 진행으로 해금. 각 국가는 5개 지역, 지역당 9개의 지역 전투. 지역 전투는 순서대로 해금(이전 전투 1회 클리어).
- 지역의 영웅 조우 전투는 반복 가능(스태미너 소모). 조우 1회 클리어 시 해당 영웅의 서사 퀘스트(계층 4·5)가 열린다.
- 출신 맹약 퀘스트: 한 출신의 계층 1~3 영웅 조우 전투 9개를 어려움 이상으로 클리어 → 계층 3 영웅 확정 + 상징.

### 2.3 장기 루프 (시즌/엔드게임)
- 악몽 난이도 전수 클리어, 3성 196명 수집, 빛나는 아이템·유물 수집.
- 주간 현상금 게시판(브로멜): 무작위 고난도 전투 7개, 추가 보상.
- 시즌 패스(미래): 신규 국가/영웅 추가 시 "확장" 형태.

## 3. 게임 구조

### 3.1 월드 구조
```
대륙 아르켄
 ├─ 1막 (위험도 1~2): 브로멜 자유도시, 아스텔 왕국, 미르 공국
 ├─ 2막 (위험도 3~5): 하르벤, 루멘, 리에스, 발하임, 카르나, 토르가, 쿠르간, 사이람, 엘로웬, 그란두르, 서리 제도
 ├─ 3막 (위험도 6~8): 티아마(해저), 베일(요정), 자이로스(정글), 녹스(흑마법), 황혼 요새, 마카브(화산), 네오스(SF), 셀레스티아(고마법)
 ├─ 4막 (위험도 9): 드라케스탄 (선한 용족의 둥지)
 └─ 5막 (위험도 10): 애쉬펠 (재의 날개 본거지)
```
국가별 상세는 [05 세계·국가·전투 설계](05_세계_국가_및_전투_설계.md), 서사는 [02 세계관·스토리](02_세계관_및_스토리.md).

### 3.2 전투 레벨과 적 전력
- 모든 전투는 **레벨 1~100**을 가진다 (국가 위험도 × 9 + 지역 보정). 레벨은 적 유닛의 계층·성급·수와 보상 골드를 결정한다.
- 난이도: **보통**(적 전력 ×1.0, 보상 ×1.0, 영웅 드랍 ×1.0) / **어려움**(×1.6, ×1.7, ×1.5) / **악몽**(×2.6, ×3.0, ×2.2).
- 적 성급: 보통 1성(고레벨은 2성 혼합), 어려움 +1성, 악몽 +2성(최대 3성).

### 3.3 전투 유형 24종 (요약)
소규모 접전, 공성전, 방어전(3웨이브), 호위, 토벌(보스), 결투(1v1 단독), 매복, 탐험(연속), 현상금, 침공(대군), 생존(5웨이브), 영웅 조우, 시련(참전 제한), 레이드, 구출, 암살(지휘관 처치 즉시 승리), 기습, 진압, 사냥, 결전(스토리 보스), 투기장(3연전), 탈출(30초 생존), 정찰, 수호(구조물 방어). 규칙 상세는 05 문서.

### 3.4 참전 조건
| 모드 | 인원 | 비고 |
|---|---|---|
| 단독 | 1 | 레온 또는 영웅 1명. 결투·일부 현상금 |
| 소대 | 2~4 | 현상금·암살·기습·정찰·투기장 |
| 부대 | 4~8 | 방어·호위·매복·탐험·생존·시련·구출·탈출·수호 |
| 대군 | 6~10 | 공성·침공·레이드·결전 |
| 자유 | 1~10 | 접전·토벌·사냥·영웅 조우 |

추가 제한(시련·퀘스트): 특정 출신만/직업만, 계층 상한, 성급 상한, 인원 상한, 특정 직업 N명 포함 등. 팀 인원 상한은 용병 레벨로 결정(Lv1 1 → Lv4 4 → Lv8 6 → Lv12 8 → Lv20 10, `economy.team_size_by_player_level`). 단, 전투의 최소 참전 인원이 상한보다 크면 최소 인원까지 허용한다(20 문서 §4).

## 4. 주요 시스템 요약

### 4.1 영웅 (→ [03 영웅 시스템](03_영웅_시스템.md))
- **계층(Tier) 1~5** = TFT의 코스트 1~5에 대응(일반/고급/희귀/영웅/전설). 계층별 기본 능력치 배율 1.00/1.14/1.30/1.48/1.70.
- **성급(★1~★3)**: 체력 ×1.8/성, 공격력 ×1.5/성, 스킬 수치 3단계. 승급은 **모든 영웅 공통 재료**(영혼의 파편·용의 정수·별의 결정 + 골드)로, 수량만 계층별로 다르다.
- **특성**: 출신 14(2/4/6/8), 직업 14(2/4/6). 영웅 1명 = 출신 1 + 직업 1. 상징 아이템으로 특성 추가.
- **전투 파라미터**: TFT와 동일 — 체력, 공격력, 공격 속도, 방어력, 마법 저항력, 사거리, 시작/최대 마나, 치명타 확률(25%)·피해(140%), 주문력(100%).
- **스태미너**: 영웅마다 100. 전투당 영웅별 10/14/18 소모(난이도별), 웨이브 전투 ×1.5. 6분당 1 회복.

### 4.2 아이템 (→ [04 아이템 시스템](04_아이템_시스템.md))
- 기본 재료 10 + 용의 비늘(출신 상징 재료) + 영웅의 문장(직업 상징 재료) = 12. 재료 2개 → 조합 아이템 55 + 상징 20 + 특수 3.
- 빛나는(강화판) 55, 유물 60, 지원 30, 국가 특산품 24, 소모품 12, 승급 재료 3. 영웅당 3슬롯.
- **모든 아이템은 로비 상점에서 골드로 구매 가능**. 전투 보상 드랍은 "무료 획득 경로"다.

### 4.3 전투 (→ [08 전투 시스템](08_전투_시스템.md))
- 가로 화면에 맞춘 **8열 × 7행 헥스 보드**(좌측 4열 아군, 우측 4열 적). 자동 전투, 30초 제한 + 연장(피해 증가).
- 타겟팅·이동·공격·마나·스킬·피해 공식 모두 TFT와 동일 체계.

### 4.4 영웅 획득 (→ [06 영웅 획득·퀘스트](06_영웅_획득_및_퀘스트.md))
- 영웅 조우 전투: 계층별 기본 드랍률 35/25/15/8/4% × 난이도 배수(1/1.5/2.2). 실패 시 호감도 누적(천장 100 = 확정).
- 영웅 서사 체인(계층 4·5 전원): 조우 1회 클리어 후 3단계 조건 전투 → 확정 영입.
- 출신 맹약 14, 직업 시련 14, 스토리 보상 5(카시안·요한나·윌로우·아젤리아·이그니스).
- 지역 전투 일반 보상에서 토착 출신 계층 1~3 영웅 2~5% 드랍.
- 중복 영웅 → 영혼의 파편 + 호감도로 전환.

### 4.5 경제·BM (→ [07 경제·BM](07_경제_및_비즈니스모델.md))
- 재화: 골드(전투·판매), 용의 보석(프리미엄: 첫 클리어·업적·구매).
- 과금 상품: 스태미너 물약, 영웅 서약서(조우 드랍 ×1.5/×2/×3), 매력 징표(호감도 +10/+50), 월정액(스태미너 회복 속도 ×1.5 + 보석).
- 능력치·영웅 직접 판매 없음. 확률형 뽑기 없음(전투 드랍만 확률).

## 7. 세계관·스토리 요약 (→ 02 문서)
- 세계는 태초의 용 **아르켄**의 심장 위에 세워졌다. 심장은 1,000년 전 "용의 전쟁" 끝에 **세계의 쐐기**로 봉인되었고, 봉인의 열쇠는 **용의 신부 이셀라의 피**였다. 봉인 이후 용의 알은 부화하지 않는다.
- 흑룡 **바르그라드**가 이끄는 **재의 날개**는 쐐기를 부숴 세계를 재로 되돌리고 용의 시대를 되살리려 한다. 그 열쇠가 이셀라의 마지막 후손, 레온의 연인 **엘리아**다.
- 레온은 일곱 왕국과 숨겨진 나라들의 영웅을 모으고, 청룡 **아젤리아**(바르그라드의 여동생)와 혼혈 용족 **카시안**(바르그라드의 아들) 등 선한 용족과 손잡아 "세계도 용도 살리는" 제3의 길 **조화의 봉인**을 찾는다.

## 8. 플랫폼·기술 요약 (→ [10 기술 사양](10_기술_사양_및_데이터_스키마.md))
- Unity 6 (2D URP), C#. 가로 고정, 기준 해상도 1920×1080, 세이프 에어리어 대응(19.5:9 ~ 4:3).
- 전투는 **결정론적 시뮬레이션**(시드 고정)으로 클라이언트/서버가 동일 결과를 재현. Python 시뮬레이터(`sim/`)가 밸런스의 기준 구현이며 C# 포팅의 레퍼런스.
- 모든 콘텐츠는 JSON 데이터 드리븐(`data/`). 생성기(`tools/`)로 재생성 가능.

## 9. 밸런스 설계 원칙 (→ [09 밸런스 시뮬레이션](09_밸런스_시뮬레이션.md))
1. **등가 모델**: 같은 계층·같은 성급의 영웅은 "같은 가치"다. 1v1 라운드로빈과 무작위 팀전 몬테카를로에서 승률 45~55% 밴드로 수렴시킨다.
2. 계층 간: 계층 n+1 ★1 ≈ 계층 n ★2의 60~70% 전력(TFT의 코스트-성급 관계 반영).
3. 아이템: 같은 분류의 아이템은 "기준 캐리어"에 장착했을 때 승률 기여가 동일 밴드.
4. 수치는 시뮬레이션 결과로만 바꾸고, 콘셉트(스킬 원형)는 유지한다.
