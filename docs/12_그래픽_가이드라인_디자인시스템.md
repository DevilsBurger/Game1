## 1. 스타일 결정: "잿빛 서사시 (Ashen Epic)"

### 1.1 한 줄 정의
**스타일라이즈드 페인터리 다크 판타지.** 왕좌의 게임의 무게감(정치·전쟁·회색 도덕)과 용족·SF가 공존하는 세계를, 사실적 비율의 **회화풍 일러스트(초상·배경·컷신)**와 **2.5등신 스타일라이즈드 전투 유닛**의 2계층 구조로 표현한다.

### 1.2 왜 이 스타일인가
| 요구 | 결정 | 이유 |
|---|---|---|
| 가로 모바일, 헥스 보드 위 최대 20유닛 | 전투 유닛은 2.5등신·굵은 실루엣·출신 색 코딩 | 작은 화면에서 유닛 식별이 승패를 좌우(TFT 경험) |
| "왕좌의 게임" 같은 서사 | 초상·컷신은 사실 비율·회화풍·절제된 채도 | 귀여운 유닛만으로는 서사의 무게가 전달되지 않음 |
| 판타지 + SF(네오스) + 흑마법(녹스) | 공통 톤(재·불씨·용의 뼈)을 유지하고 국가별 팔레트/재질로 변주 | 세계가 하나로 보이면서 국가 간 차이가 즉시 읽힘 |
| 미드저니 생산 | 기술 묘사 기반 프롬프트 + 스타일 레퍼런스(`--sref`) 고정 | 196+120+282+120장의 일관성 확보 |
| 196 영웅 × 3성급 | 성급은 초상 **테두리·배경 이펙트**로 표현, 일러스트는 1장 | 제작량 1/3, TFT도 동일 |

### 1.3 금지 사항
- 포토리얼(실사 합성 느낌), 과포화 네온 전면 사용(네오스 악센트만 허용), 글리터/과도한 렌즈 플레어.
- 유닛 간 구분이 안 되는 저대비 의상. 같은 직업·다른 출신 유닛은 **색과 실루엣** 중 하나는 반드시 달라야 한다.
- 텍스트가 들어간 이미지(미드저니는 글자를 깨뜨림 → UI 텍스트는 엔진에서 렌더).

### 1.4 무드 키워드 (프롬프트 공통 앵커)
`painterly digital illustration, stylized dark fantasy, ash-grey atmosphere with ember-orange accents, dramatic rim light, muted palette with one saturated accent, cinematic composition, high-end mobile RPG splash art quality, clean readable silhouette, no text`

## 6. 캐릭터 아트 규격

### 6.1 초상 (Portrait) — 영웅 196 + 레온·엘리아, 몬스터 120(보스 24는 전신)
- 원본 **1024×1024**(미드저니 --ar 1:1 업스케일). 인게임: 512(상세), 256(카드), 128(목록), 64(전투 체력바 옆).
- 구도: 가슴 위 3/4 측면, 시선은 카메라 또는 약간 좌측, 얼굴이 프레임 높이의 45~55%. 배경은 출신 팔레트 단색 그라데이션 + 재 입자(엔진 오버레이 가능하도록 단순).
- 조명: 키라이트 좌상, 림라이트는 출신 악센트 색. 채도는 얼굴 중심, 의상은 한 톤 낮춤.
- 성급 표현: 테두리(은/금/불씨금) + ★3는 배경에 불씨 입자(엔진).

### 6.2 전신 스탠딩 (Standing) — 영웅 196 + 레온·엘리아
- 원본 **1024×1536**(--ar 2:3). 로비·영웅 상세·영입 연출. 전신, 무기·직업 아이덴티티 노출, 발끝까지.
- 포즈: 직업별 기본 포즈(기사: 방패 앞, 궁수: 활 당김 직전, 마법사: 주문 준비 등). 배경 투명(누끼) — 미드저니 후 배경 제거.

### 6.3 전투 유닛 (Battle Unit) — 영웅 196 + 레온 + 몬스터 120 + 소환수/포탑 14
- **2.5등신 스타일라이즈드**, 3/4 뷰(보드 등각에 맞춤), 좌우 반전 사용(적은 우→좌). 머리·무기가 실루엣의 핵심.

## 12. 스타일 레퍼런스 고정 절차 (미드저니)
1. **앵커 세트 생성**: §1.4 무드 키워드로 "초상 3장 + 배경 2장 + 아이템 2장 + 유닛 시트 1장"을 생성해 아트 디렉터가 선택 → `--sref` 코드 확정(초상/배경/아이템/유닛 4종).
2. 모든 프롬프트는 `[카테고리 공통 프리픽스] + [대상 서술] + [출신 팔레트] + [카테고리 공통 서픽스] --sref <코드> --ar ... --stylize 150~250`.
3. 같은 영웅의 초상/전신/유닛 시트는 `--cref <초상 URL> --cw 60~80`으로 얼굴·의상 일관성 유지.
4. 결과 검수 체크리스트: 실루엣 식별 가능? 출신 색 60/30/10? 텍스트/워터마크 없음? 손·무기 파손? 배경 단순?
