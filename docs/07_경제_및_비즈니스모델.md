# 07. 경제 및 비즈니스 모델

> BM: 케릭터가 전투에 참전할 수 있는 **스태미너**와 케릭터 보상 **드랍 확률을 높이는 문서(영웅 서약서) · 매력 징표**. 모든 아이템은 로비에서 골드로 구매 가능.
> 원본: `data/economy.json`, `data/items.json`(consumable).

## 1. 재화

| 재화 | 획득 | 소비 | 비고 |
|---|---|---|---|
| **골드** | 전투 보상(주), 아이템 판매(구매가 30%), 퀘스트, 일일 의뢰 | 아이템 구매(전 품목), 승급 골드, 소모품(골드 경로) | 인플레이션 방지: 재료 일일 구매 한도, 고가 아이템 가격 |
| **용의 보석** (프리미엄) | 첫 클리어 보너스(지역 5~15, 스토리 30~70), 업적, 도감, 구매 | 소모품(보석 경로), 월정액 대체 구매, 스킨 | 1보석 = 100골드 일방향 교환 가능 |

| 호감도 | 조우 실패, 중복, 매력 징표 | 확정 영입 / 코스메틱 | 영웅별 0~100 |

## 2. 골드 경제 흐름

### 2.1 수입 (무과금 평균, 하루 2시간)
- 하루 참전 약 25회(스태미너 240/영웅, 평균 6인 편성, 보통·어려움 혼합). 2막 기준 전투당 평균 900골드 → 약 **22,000골드/일**.
- 첫 클리어 보너스: 신규 전투 10개/일 × 400 = 4,000.
- 합계 약 26,000골드/일 (2막), 1막 8,000, 3막 50,000, 5막 90,000.

### 2.2 지출 (목표 비율)
| 항목 | 비율 | 예 (2막 하루 26,000) |
|---|---|---|
| 승급 골드 | 35% | ★2 승급 4~6회 |
| 아이템 구매·조합 | 35% | 조합 아이템 10개 또는 유물 3개 |
| 소모품(골드) | 20% | 스태미너 물약·서약서·징표 |
| 재료 보충 | 10% | 파편 100 + 정수 5 |

골드로 살 수 없는 것은 **시간**뿐이다. 영웅 1명의 등가 골드 가치(1,500~40,000)와 조합 아이템 900, 유물 2,800을 기준으로 전투 보상 곡선을 맞췄다.

### 2.3 가격표
| 분류 | 골드 |
|---|---|
| 기본 재료 | 300 |
| 조합 아이템 | 900 (재료 2개 600 + 편의 프리미엄) |
| 상징(조합) / 비조합 상징 | 1,500 / 2,500 |
| 특수(용의 심장 등) | 3,000 |
| 지원 아이템 | 1,800 |
| 국가 특산품 | 2,200 |
| 유물 | 2,800 |
| 빛나는 | 3,500 |
| 승급 재료 | 40 / 250 / 1,500 |

## 3. 스태미너 설계 (BM 축 1)
- **왜 영웅별 스태미너인가**: 팀 전체 스태미너라면 영웅 수집이 플레이 시간과 무관해진다. 영웅별 스태미너는 "많은 영웅 = 더 많은 참전 = 더 많은 보상"을 만들어 수집 동기와 BM이 충돌하지 않는다.
- 하루 영웅 1명 참전 가능 횟수: 보통 24회, 어려움 17회, 악몽 13회(웨이브형은 2/3).
- 과금 상품: 스태미너 물약 소/중/대(10/22/40보석), 부대 보급(70보석, 전체 +30), **월정액 '용병 계약'**(4,900원 상당: 회복 속도 ×1.5 + 일 50보석 + 상점 10% 할인).
- 상한: 하루 보석 스태미너 구매 10회(과몰입 방지).

|---|---|---|---|---|
| 영웅 서약서(일반) | 조우 드랍 ×1.5 (1회) | 600 | 30 | 문서형 |
| 영웅 서약서(고급) | ×2.0 | 1,400 | 60 | |
| 영웅 서약서(전설) | ×3.0 | — | 150 | 보석 전용 |
| 매력 징표 | 지정 영웅 호감도 +10 | 500 | 25 | |
| 매력 징표 묶음 | +50 | — | 110 | 보석 전용 |
| 영웅의 부적(지원 아이템) | 조우 드랍 +10%p | 1,800 | — | 장비, 영구 |

**기대값 설계** (계층 5, 악몽 8.8% 기준):
- 무과금: 평균 11.4회, 최대 34회(천장) 조우. 조우 1회 = 스태미너 6인×18 = 108 → 하루 2회 → 최대 17일.
- 전설 서약서(26.4%)를 매 조우에 쓰면 평균 3.8회, 보석 570 ≈ 5,700원 상당. 징표 묶음 2개(220보석)로 즉시 확정도 가능 → **계층 5 영웅의 보석 가치 상한 ≈ 220~570보석**.
- 확률 공개 의무: 조우 전투 UI에 계층별 기본 확률·보정 후 확률·현재 호감도 표시.

## 5. 과금 원칙
1. 능력치·영웅·아이템 직접 판매 없음(아이템은 골드 판매만). 보석→골드 교환은 가능하므로 간접적으로 '시간 구매'.
2. 확률형 뽑기 없음. 확률은 전투 드랍에만 존재하며 모두 천장(호감도)과 확정 경로(퀘스트)가 있다.
3. 가성비 순서: 월정액 > 징표 묶음(원하는 영웅 확정) > 서약서 > 스태미너 물약.
4. 코스메틱(영웅 스킨·보드 스킨·레온 의상)은 보석 전용, 능력치 무관.

## 7. 매출 모델 (가정)
- DAU 10만, 과금 전환 5%, ARPPU 월 25,000원 → 월 1.25억. 주 매출원: 월정액 45%, 징표/서약서 35%, 스태미너 15%, 코스메틱 5%.
- KPI: D1 45% / D7 20% / D30 10%, 평균 세션 12분, 일 세션 4회.

## 8. 경제 밸런스 점검 항목
- 골드 수입 대비 승급 비용: 계층 5 ★3까지 40,000골드 + 별의 결정 8 → 악몽 레이드 8회 이상. 엔드게임 목표로 적절.
- 조합 아이템 공급: 무료 드랍(8~18%)만으로 2막 종료 시 약 20개 보유 예상 → 팀 6인 × 3슬롯 18 충족.
- 스태미너 로테이션: 보유 영웅 30명 시 하루 참전 상한 ≈ 120회(2시간 이상) → 스태미너는 라이트 유저의 병목이 아님. 헤비 유저만 구매 → BM이 "강제"가 아닌 "선택".
